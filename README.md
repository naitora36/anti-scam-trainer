# Проект «Антискам-тренажёр»

«Антискам-тренажёр» – учебное веб-приложение для отработки безопасного поведения на классифайде через ветвящиеся диалоги.

* **Исходный командный репозиторий:** [marlendd/anti-scam-trainer](https://github.com/marlendd/anti-scam-trainer)
* **Мои коммиты в исходном репозитории:** [История коммитов naitora36](https://github.com/marlendd/anti-scam-trainer/commits?author=naitora36)
* **GitHub:** [@naitora36](https://github.com/naitora36) (Люлин Ярослав)

## Назначение этого репозитория

Это отдельный публичный репозиторий для индивидуальной оценки моего вклада в командный проект.

Этот репозиторий предназначен для просмотра материалов. Полностью собираемая версия приложения и инструкции запуска находятся в исходном репозитории.

## Моя роль

**Backend-разработчик на Go**. Основной фокус моей работы заключался в проектировании и разработке модуля прогресса (система геймификации, лидерборды, ранги), интеграции LLM для генерации обратной связи, настройке CI-пайплайнов и обеспечении качества через интеграционное тестирование. 

## Принятие технических решений и архитектурный вклад

* **Архитектура модуля прогресса:** спроектировал логику хранения и обновления пользовательских достижений (рангов, пазлов), обеспечив консистентность данных при конкурентных запросах.
* **Отказоустойчивость LLM:** разработал механизм взаимодействия с нейросетью с обязательным **детерминированным fallback-механизмом**. Это гарантирует, что пользователь всегда получит осмысленную обратную связь даже в случае недоступности внешнего API или таймаутов LLM.
* **Расчёт метрик:** реализовал бизнес-логику оценки успешности прохождения сценариев, связав результаты действий пользователя (engine) с системой выдачи наград.
* **CI/CD:** настроил пайплайн непрерывной интеграции для автоматического прогона тестов и проверок, гарантируя стабильность кодовой базы при слиянии веток.

## Реализованные части

### 1. Модуль прогресса и геймификация
* разработка API для получения сводки профиля пользователя;
* реализация глобального лидерборда и истории изменения рангов;
* бизнес-логика расчета метрик успешности прохождения сценариев;
* интеграция системы «пазлов» как элемента вознаграждения.
* **Код и тесты:** `backend/internal/progress`

### 2. Интеграция LLM и система обратной связи
* подключение LLM-модели для анализа действий пользователя и генерации персонализированного фидбека по результатам попытки;
* реализация fallback-стратегии: отдача заранее подготовленных (детерминированных) советов при ошибках сети или падении стороннего сервиса;
* **Код:** `backend/internal/feedback`, `backend/internal/llm` *(уточни пути, если они отличаются)*

### 3. База данных и SQL-миграции
* проектирование схемы данных для хранения метрик прогресса, истории рангов и инвентаря наград;
* доработка SQL-миграций для обеспечения атомарности выдачи наград и консистентности прогресса.
* **Код:** `backend/migrations/`

### 4. Инфраструктура, CI и тестирование
* настройка CI-пайплайна в GitHub Actions для автоматизации проверок (линтеры, тесты);
* написание интеграционных тестов для проверки логики прогресса на реальной базе данных;
* проверка корректности расчётов лидерборда и начисления наград.
* **Код и конфигурация:** `.github/workflows/`, файлы `*_integration_test.go` в модуле прогресса.

### 5. OpenAPI-контракт
Дополнял общий файл `backend/openapi.yaml` спецификациями для своих модулей:
* эндпоинты модуля прогресса (лидерборд, сводка профиля, история рангов);
* эндпоинты запроса обратной связи и результатов прохождения;
* описание структур ответов (включая fallback-ответы) и возможных ошибок HTTP.
